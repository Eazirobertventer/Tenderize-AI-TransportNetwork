## Delivered

### National coverage gap model

New module:

`apps/transport-api/src/national-coverage.mjs`

The model covers all nine provinces:

- Gauteng
- KwaZulu-Natal
- Western Cape
- Eastern Cape
- Free State
- Limpopo
- Mpumalanga
- North West
- Northern Cape

It measures:

- canonical active ranks;
- mapped ranks;
- location-pending ranks;
- canonical active associations;
- canonical routes;
- ranks without canonical association links;
- active data issues;
- rank-association candidates;
- route candidates without association;
- canonical routes without association;
- routes with unresolved canonical endpoints;
- official/authoritative source-record opportunity;
- documented source-record opportunity.

### National totals and unscoped backlog

National totals are queried directly from the full corpus rather than summed only from province-attributable rows.

This preserves backlog that cannot yet be attributed to a province.

The response includes an explicit `unscoped` residual for:

- rank coverage gap;
- route coverage gap;
- route-candidate association gap.

No unresolved data is hidden in a synthetic tenth province.

### Operational priority model

Province and municipality rows receive an operational backlog priority derived from:

- coordinate gaps;
- missing association links;
- unresolved route endpoints;
- unassigned route records;
- active data issues;
- bounded authoritative/documentary evidence opportunity.

Priority bands:

- critical
- high
- medium
- low
- complete

The score is explicitly:

**not canonical confidence, not evidence truth, and not an automatic promotion score.**

It is only a work-queue ordering mechanism.

### Completeness indicator

Coverage completeness combines:

- coordinate completeness;
- canonical association-link completeness.

It does not change entity verification status.

### Read-only coverage APIs

New endpoints:

`GET /api/v1/coverage/national`

Optional:

`?province=<province>`

returns municipality drill-down for the selected province.

`GET /api/v1/coverage/gaps`

Optional:

- `province`
- `municipality`

returns mapped rank GeoJSON for ranks with one or more explicit gap classes:

- `missing_association`
- `active_issue`
- `association_candidate`

### Operator workbench

The ADJ9 private operator workbench now includes a **Coverage** view.

It displays:

- national rank count;
- mapped count;
- ranks without association;
- unresolved route endpoint count;
- province priority ordering;
- priority band;
- priority score;
- coverage completeness;
- location-pending count;
- association gap count;
- route endpoint gap count.

The workbench coverage object remains read-only and carries:

`canonicalMutationEnabled:false`

### Operational map

The public operational map now includes:

**Coverage gaps on/off**

The new map layer:

`coverage-gap-points`

uses explicit gap classes rather than inferred canonical changes.

Mapped gaps are visually differentiated:

- missing canonical association;
- active data-quality issue;
- association candidate available.

Clicking a gap rank drills back into the existing rank inspection workflow.

Satellite, route, association and Street View workflows remain intact.
