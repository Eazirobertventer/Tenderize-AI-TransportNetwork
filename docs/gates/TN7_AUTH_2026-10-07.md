## Delivered identity boundary

The Transport API now verifies short-lived signed Bearer JWTs on protected operator routes.

Verification is fail closed and validates:

- HS256 algorithm only;
- trusted issuer;
- trusted audience;
- non-empty subject;
- expiry;
- not-before;
- issued-at future skew;
- HMAC signature using constant-time comparison;
- recognised role.

A verifier secret shorter than 32 bytes or missing entirely makes protected routes return `503 operator_auth_unconfigured`.

The API does not issue operator tokens and no verifier secret is shipped to the public Web/browser.
