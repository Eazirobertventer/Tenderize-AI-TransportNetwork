## Objective

NATIONAL-3 expands the KZN operating-licence / provincial-gazette evidence set beyond the 11-row NATIONAL-2 seed and turns the combined evidence into a bounded operator queue.

It does not automatically create or modify:

- taxi associations;
- rank-association relationships;
- route-candidate association assignments;
- canonical routes;
- aliases;
- merge state.

All deterministic promotion remains behind the existing ADJ5/ADJ6 operator controls.

## Direct PDF corpus execution

A general-purpose KZN corpus executor was added:

`apps/kzn-licence-corpus-worker/tn7-national-3-corpus.mjs`

It:

- parses complete gazette documents with the existing KZN parser;
- runs database reconciliation in `BEGIN READ ONLY`;
- isolates document failures;
- emits a bounded queue capped at 250;
- can expose read-only `/summary` and `/queue` result endpoints;
- never writes canonical or candidate data.
