## Objective

NATIONAL-2 moves KZN from NATIONAL-1 backlog measurement into source execution.

The gate does not promote canonical truth automatically.

It executes and classifies available evidence so operators can distinguish:

- exact evidence ready for controlled review;
- partial endpoint association evidence;
- conflicting/multiple association evidence;
- unresolved evidence;
- already-canonical evidence.

## Source strategy

The KZN execution path reuses the proven TN6 source architecture:

1. KZN Department of Transport taxi-rank GIS;
2. KZN Department of Transport taxi-route geometry;
3. KZN operating-licence / provincial gazette route evidence;
4. exact route-code matching where a verified route-code cross-reference exists;
5. canonical association identity matching;
6. existing adjudication primitives for any later promotion.

Policy:

- spatial proximity alone is not association proof;
- verified gazette join requires exact route-code equality;
- evidence-ready classification requires one unambiguous canonical association identity;
- ambiguous/colliding evidence remains review-required;
- canonical mutation is disabled in NATIONAL-2;
- promotion must use the existing controlled adjudication workflow.

## Reusable KZN execution model

New module:

`apps/transport-api/src/kzn-coverage.mjs`

New packaged verified evidence manifest:

`apps/transport-api/data/kzn-verified-route-association-evidence.json`

New read-only API:

`GET /api/v1/coverage/kzn/execution`

The endpoint reports:

- KZN rank and association coverage;
- route-candidate coverage;
- endpoint association evidence buckets;
- source inventory;
- municipality attribution;
- verified gazette route/association joins;
- evidence classification;
- exact candidate/canonical route matches;
- canonical-mutation state.

## Schema compatibility

The normal TN7 preview remains on the production-compatible pre-adjudication schema.

NATIONAL-2 therefore reads optional later columns through `to_jsonb(...)`:

- association aliases;
- route `source_route_code`.

This allows the source-execution model to run on both:

- TN6-compatible preview schema;
- full TN7 adjudication schema.

No migration is required for NATIONAL-2.
